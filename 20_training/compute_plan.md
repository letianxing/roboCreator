# 训练算力计划（初稿）

## 已确认

- 用户计划使用 AutoDL 租用 GPU 训练，倾向 RTX 4090。
- 用户授权助手规划训练资源与流程；当前未授权实际付费开机或充值。
- 具体实例、显存、驱动、系统镜像、平台可用性与小时价尚未核查。不预估未经试跑的训练时长或收益。

## 分阶段使用算力

1. 本地完成模型结构、单位、关节轴、惯性、碰撞和基础控制检查；本地资源不足的测试记录为待云端执行。
2. 根据最终任务比较 MuJoCo/mjlab 与 Isaac Lab 训练路径。模型采用共享参数源并维护平台适配，不预先同时部署两套大型环境。
3. 租卡前核实 RTX 4090 实例、实际显存、驱动/CUDA/框架兼容性、容器/图形上下文限制、磁盘和数据传输条件，以及许可证和现行价格。
4. 以无界面训练为目标，先进行少量并行环境、短时间训练和保存/恢复测试，记录显存、吞吐率、失败率和费用。
5. 根据实测吞吐率和训练步数估算费用；逐步调整并行数量，不将最大可开环境数直接视为最优配置。
6. 分任务推进基础站立/步行、受控躺下/起身、表现性动作、操作与对打任务。具体顺序按硬件能力和动作依赖调整；不假定一个策略覆盖全部任务。
7. 定期下载 checkpoint、配置、随机种子和日志，设置可执行的时长/费用边界；任务结束核查实例停止，保留恢复所需文件。

## 预算口径

租卡、存储及传输费用单独列为研发算力费用。暂不占用已定义的 5,000 元硬件额度，但该口径仍属规划假设；任何付费操作前提供实际报价、试跑限额及预计费用，确认总支出范围。当前未租卡、未训练、未产生费用。
