# v0.22 电气布局与局部抬身区间评审

日期：2026-09-06。研究交付，非制造/真机放行。保留28DOF、30–40cm与可爱齐天大圣要求；未新增软件或MCP、未运行新结构有限元、未执行硬件动作、未推送GitHub。PLM/MES仍后置。

## 本轮结果

解决v21在较低抬身位置的电池/电源占位干涉。在身体参考高114–120mm、35°前倾、左脚/右膝/右掌位置保持、左臂抬起的局部姿态族中，**13个0.5mm间隔采样全部通过本轮几何、名义2mm电气模块净间隙及非负竖直反力检查**。这只是6mm身体参考高度区间，不是机器人完整起身高度，也不是连续碰撞证明。

站姿同样通过本轮检查。已建站姿包络约167.818×289.400×394.265mm（深×宽×高），与v19站姿相同；质量/额度约4.072502kg，未增加已建器件质量。真实安装件仍缺，不能当最终实物重量或完整穿戴尺寸。

## 固定布局变化

| 模块 | 相对v21的机身坐标位移（mm） | 新中心（mm） |
|---|---|---|
| 电池 | X−4，Z+4 | (−4,0,72) |
| 控制板 | X−4 | (−54,0,92) |
| 电源模块 | X−12 | (−17,0,38) |

各模块形状、方向和体积保持不变，没有缩小占位来消除碰撞。电源累计相对v19后移17mm。选择过程先独立检查每个模块与四个离散场景固定障碍，再检查模块组合；1mm筛查留下42个组合，2mm筛查留下4个，选取其中总平移量最小者。参数与选择分别在`03_system/electronics_motion_v22.json`、`selected_electronics_v22.json`。

保存CAD的精确最近间隙：114mm姿态电池—大腿板约3.299mm，其余所查姿态电池最近间隙约4.750mm；电源—骨盆板、控制板—麦克风最小均约2mm。站姿电池底面到骨盆板顶面约6mm。上述为空间测量，不是支架、连接器、线束、绝缘或散热验证；详见`07_mechanics/electronics_interfaces_v22.md`和同名JSON。

## 重心与稳定性限制

同一抬身姿态下，本次平移使COM约后移0.210mm、上移0.411mm，支撑余量约减少0.193mm，**不是同姿态重心改善**。价值在于解除了原本碰撞、但静态余量更大的低姿态，使其可作为下一步动作研究候选。

| 身体参考高 | 新静态支撑余量 |
|---:|---:|
| 114mm | 12.264mm |
| 117mm | 7.712mm |
| 118mm | 5.857mm |
| 119mm | 3.728mm |
| 120mm | 1.173mm |

114mm时右掌理论可分担的竖直力上限约8.688N；所有反力均为平地、重力和单向接触的准静态计算。未计摩擦锥、惯性、接触柔度、尺寸/质量误差与控制器。120mm端点余量依然很小，不能作为稳定起身定型或部署依据。

## 验证方法和未覆盖项

- 6个新增半毫米中间姿态重新求IK，双腿前向/逆向闭合复核；整数姿态保留v21原关节解，避免悄然换分支。
- 114/117/119mm三个整数姿态、全部6个新中间姿态及站姿进行了已建形状全配对检查；其余4个不变整数姿态复用v21未改变配对的完整证据，只重新检查移动模块配对。所有13点均检查移动模块2mm间隙。
- 检查了体积/质量保持、COM平移公式、竖直力和力矩平衡、站姿包络以及原生CAD保存后重开。相邻0.5mm采样最大单关节角变化约2.606°，但没有时间参数、速度/力矩可行性或真实控制指令。
- 尚未证明采样点之间的连续扫掠、完整换掌/落脚/右膝卸载至站立、递水等其他动作回归、真实安装/布线、CAE强度/热/冲击或真机能力。头冠仍是占位，最终齐天大圣外观未通过。
