# 整机CAD / CAE剩余工作估计

2026-09-06，回应用户“还需要几轮”。估计约8–12个有效工作轮次，目标是可加工装配的整机CAD和关键工况CAE评审包；不是完成保证、日历工期，也不包含真机标定、系统辨识、策略训练及实测验收。发生执行器/关节架构重构时必须重新估计。

| 工作包 | 暂估轮次 | 交付及退出条件 |
|---|---:|---|
| 起身与空间布局收敛 | 2–3 | 同坐标全身候选、接触序列、路径碰撞/ROM检查，不能只保存几个静态姿态 |
| 实际承力连接与装配细化 | 2–3 | 肩/肘/髋等轴承、轴、连接架、紧固件、线束与工具空间；逐件可装配，不以占位盒替代接口 |
| 载荷与结构CAE迭代 | 2–4 | 对应版本载荷、材料/边界、网格收敛、应力/变形/连接/稳定性检查与未满足项；优先FreeCAD FEM/Gmsh/CalculiX |
| 齐天大圣穿戴与交付审查 | 1–2 | 认可的可爱悟空外观、装甲/布衣活动余量、相机/麦克风空间及穿戴后任务检查、制造装配包与成本汇总 |

部分工作可以交叠，表中轮数不可直接相加作为工期。每轮完成一个可验证工作包，并保存检查点。当前v0.20已建模型不代表整机CAD临近制造发布；肩部实际支撑、肘连接、完整起身、负载及最终外观仍有缺口。

尤其是硬地面跌倒/起身、跳跃及前后侧空翻，需要额外的动态接触、冲击、执行器速度/力矩/温升证据。CAD/关键CAE评审包完成不自动证明所有动作可行或允许上机；若这些任务触发架构更改，8–12轮估计失效，必须及时报告并重新规划。PLM/MES仍在原型完成后提供完整方案，不纳入当前前置门槛。
