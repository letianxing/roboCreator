# 紧凑架构对照 v0.13

## 本轮结论

形成了一个比v0.12更窄、递水静态力矩更低的26自由度研究候选。递交和撑地中间姿态在所建电机/电子包络层面取得进展，但新增传动结构、齐天大圣头壳兼容和腾空能力仍未通过。**该版本不是整机制造基线。**

## 具体调整

- 髋部虚拟yaw/roll/pitch轴更接近同一支撑中心，通过轴向错开电机占位缩短侧向力臂；实际中心万向架、输出连接及轴承尚待设计。
- 脚中心距由260mm变为200mm，保留150×90mm的原踝足研究模块，脚外宽由350mm变为290mm。没有假设把原重型踝部凭空变轻。
- 上臂/前臂参考长度由80/80mm改为95/100mm。肩部由3轴改2轴，腕部由1轴改2轴，总驱动数仍26。
- 曾尝试让末轴沿前臂自转，但它不改变末端接近方向，不能满足当前位置+方向约束；最终使用两轴弯曲腕X/Y。
- 夹爪驱动移到前臂占位，通过尚待设计的传动跨越腕部；没有直接把直线示意当可用缆索路径。
- 保留参考电机本体质量，轴、支撑、联轴和夹爪传动另加质量额度。
- 电子器件旋转/重排，不缩小原器件体积来制造虚假空间。麦克风改为躯干后部竖直占位，其声源定位算法、前后歧义和声学开口需要重新评估。

## 对比结果

| 项目 | v0.12 | v0.13 |
|---|---:|---:|
| 驱动自由度 | 26 | 26 |
| 脚外宽 | 350mm | 290mm |
| 站立冠顶 | 390mm | 390mm |
| 质量预算含外观 | 6.381kg | 6.504kg |
| 相同递交目标的髋roll力矩幅值 | 1.764Nm | 0.100Nm |
| 相同递交目标的最大准静态关节需求 | 1.844Nm | 0.854Nm |
| 相同撑地中间目标的手臂IK | 未达阈值 | 找到位置/方向解 |
| 撑地候选的电机/电子包络穿透对数 | 4 | 0 |

质量反而增加约123g，不能称为减重成功。减少的两台大电机被更多小关节、较长手臂和传动质量部分抵消；足踝偏重的问题还在。

站立手臂由下垂改为无瓶的准备姿态，因此不能把两版本站立最大宽度或力矩差全部归因于机构改变。脚外宽是独立于手臂姿态的可比较指标。

## 没有掩盖的失败点

原100mm前方取瓶目标保留：触瓶时仍有4对腕部驱动—膝电机重叠，抬瓶时有2对。没有用另一个成功点替换这些失败记录。

另增150mm前方取瓶/抬瓶工作区候选，其末端目标可解，所建电机/电子包络无穿透。该结果只说明存在一个可继续设计的操作位置，不证明机器人能自主拿到任意摆放的瓶子，也不包含完整路径、夹持、线缆和真实手掌接触。

准备姿态、递交、撑地中间姿态、150mm前方触瓶和抬瓶共5个离散姿态，没有所建电机/电子占位之间的穿透；各姿态仍存在驱动与肩甲、头壳或耳部的冲突。因此不能宣布穿戴齐天大圣外观后动作通过。

## 腾空与驱动能力

为避免换了站姿后夸大性能，另作同一COM推蹬行程19.44mm、腾空100mm的比较：

- v0.12双脚均分的等效竖向力约192N/脚；v0.13约196N/脚。由于质量增加，这项没有改善。
- 冻结姿态的等效加速度力矩峰值从约9.53Nm降到8.00Nm，仍高于AK40参考模块4.1Nm峰值。该计算不是完整动态逆动力学，不可据此给出空翻通过/不可行的最终结论。
- 原取瓶点的准静态膝需求约1.30Nm，接近AK40参考1.3Nm额定值，没有足够设计裕量；真实传动损耗会进一步提高电机侧需求。

驱动调查见 `06_actuators/architecture_sources_v13.md`。较小的XM430上肢方案有质量优势，但0.82Nm持续指标是厂家店铺按堵转值20%估算，未据此完成热和动态选型。没有因为价格放开就直接换成更重的大模块。

## 仍须解决的结构问题

1. 轴向移位的电机在概念上朝虚拟关节方向输出，但中心架、联轴、轴承和孔型尚未实体化，现有直杆不是完整传动。
2. 腕部与夹爪的驱动占位改善后，跨腕传动、效率、间隙、刚度及线束仍需设计。
3. 当前AK级肩驱动会侵入猴脸/耳部或肩甲空间。应调整驱动和机构，同时保留齐天大圣辨识特征，不能把删去角色特征当解决办法。
4. 镜像模型和小型驱动安装方向是研究假设，尚未逐个核对厂家孔位；所有结果不等于可加工装配。
5. 关节角色发生变化，旧策略、零位和控制通道配置不得直接复用。
