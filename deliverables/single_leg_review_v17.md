# v0.17 单腿集成与护腕接触评审

本轮交付一套从踝到髋的六关节单腿研究模型，以及护腕固定接触的逆运动学对照。修正版单腿在5个离散姿态中完成所有已建零件的体积交叠检查，包含上轮曾被排除的连接对；当前没有发布制造图纸或宣称整机能起身。

功能优先、重量可妥协、30–40cm及齐天大圣成品任务继续有效。建议把双肩各增加一个旋转自由度的28 DOF方案作为后续优先候选，同时保留26 DOF对照。电机选型和控制映射仍需验证。

## 先纠正 v0.16 的验证范围

上轮检查明确排除了一些“连接对”，因此其无非预期穿透结论不能证明这些连接成立。本轮读取原CAD，对全部形状对复核，中立踝存在下列体积重叠：

| 形状对 | 重叠体积 |
|---|---:|
| 固定框 / 活动支架 | 5.0mm³ |
| 轴承占位 / roll电机模型 | 593.0mm³ |
| 轴承占位 / 活动支架 | 107.8mm³ |
| 活动支架 / pitch电机包络 | 7.6mm³ |
| 活动支架 / 脚架 | 626.8mm³ |

固定框本身有2个互不相连的实体，与中央轴承占位最近还相距25mm，缺实际连接。原杆与曲柄也以相交圆柱代表铰接，并未形成销孔。原始CAD不改动，复核记录与SHA-256在 `11_verification/v16_interface_audit_v17.json`；旧的通过声明只保留为当时有限检查的历史记录。

## 单腿连接与接口修正

完整轴序为髋yaw、髋roll、髋pitch、膝pitch、踝roll、踝pitch；3个AK40与3个XM430参考驱动均纳入。大腿90mm；膝到踝roll轴53mm、roll到pitch轴37mm，合计90mm；pitch轴距基准地面35mm。髋的3轴之间各有24mm竖直偏置，不能再当成共点理想关节。

完成直腿参考、微屈站立、70°膝下蹲、100°膝深蹲探查，以及抬脚探查共5个CAD/STEP。脚的世界姿态先给定，再向上计算每个刚体变换；因此下蹲时不会把脚底任意转进地面。抬脚只是独立姿态，尚无统一骨盆的双腿步态轨迹。

膝驱动沿轴偏置0/15/25/35/45/55mm作对照。35mm时无体积交叠，但最近间隙仅1.66mm；45mm通过本轮2mm目标，最终修正版最小膝电机间隙约4.9mm。55mm会与外侧大腿板冲突，说明偏置并非越大越好。

修正版实际增加/改变了以下实体：

- 固定框前后两侧外移并增加横梁、带孔轴承座；轴承环移到电机本体外侧。
- 活动支架开出电机避让空间和roll轴孔，增加轴套形状。
- 脚架两侧移开，参考足宽65→66mm，补pitch轴孔；这只是工程尺寸调整，30–40cm身高目标不变。
- 加入roll输入延长轴、输出轴、销轴；曲柄和推拉杆改成分层、带孔形状，消除原先用实体穿透表示铰接的情况。
- 大腿板与小腿板分层摆放，并加入一段待验证的线缆维护空间。

未修接口的集成对照保留在 `09_cad/single_leg_v17/`；修正版位于 `09_cad/single_leg_v17/interface_revision/`。所有已建形状对都进入体积检查，没有按“应该连接”排除。5个修正姿态的正体积交叠对数均为0。

这些轴承环、轴和孔仍是尺寸研究件：尚未确定厂商轴承型号/配合、AK输出面及螺纹深度、联轴/紧固、防松和上部髋膝接口。零体积交叠不等于所有零件已固定；模型里仍可看到待补的连接位置。数据中的轴承质量按均匀钢环估算，不能当作标准轴承实测质量。

本轮五姿态均为踝roll=0的矢状面探查。改过轴承座与脚架后，之前的±25° roll检查不能自动继承；连续运动、roll/pitch组合、双腿互碰和穿戴外壳需要重新验证。

## 全尺寸和质量反馈

修正版单腿直立外包络约110×123×313.7mm；若按原120mm脚中心距对称放置，上部驱动与板件会把双腿外包络推到约268mm。**v0.16局部足踝的185mm外宽不能代表整条腿、更不能代表整机宽度。** 当前上部安装还是偏宽，应继续比较髋膝的安装层次与传动，不能靠盔甲遮住。

直腿模型设置的冠顶目标点为395mm，距鞋底最低点约397mm。这个点只检查尺寸链，未装入实际躯干、头部、相机、麦克风和冠饰，不能据此称已满足最终高度及审美要求。

修正版已建单腿质量约1.179kg，含6个参考电机和已建结构；双腿约2.358kg。这是“已建几何按密度估算＋电机资料质量”，不含全部紧固件、配线、软垫、外壳及尚未建模的连接件。

若选28 DOF，对应上肢/颈/夹爪剩余电机本体参考约0.840kg，沿用电气450g、外观200g额度，则已经约3.85kg，仍缺上肢与躯干结构、真实配线/紧固、其他附件及预留。**这不是最终总重或可采购BOM，旧3.708kg预算不再作为成品预测。**

## 护腕接触：自由度和安装朝向必须一起考虑

护腕垫固定在前臂，所以位于它下游的两根腕轴不会改变该垫的位置和法向。脚本直接扰动两个腕关节并复核，垫位置与法向变化均为0。此前手掌点能到达，不能据此推断护腕也能到达并平放。

以80mm上臂、85mm前臂、既有护腕几何为基础，对比：

- 26 DOF：每臂肩2、肘1、腕2；护腕位姿实际只由肩/肘3轴控制。
- 28 DOF：每肩增加一个旋转轴，肩/肘共有4个上游关节；另外把护腕安装绕前臂旋转180°作为候选。

机身高度、俯仰与接触目标也参加明确记录的搜索，共72个数值案例，保留所有失败结果。26 DOF有限多起点搜索未找到满足本组位置/法向阈值的解；这不证明所有26 DOF布局都不可能。28 DOF得到2个满足IK数值阈值的姿态，但用真实手部CAD检查地面后，其中1个因接触垫角部穿地约0.65mm被拒绝。

剩下1个可继续研究的手部姿态：

| 项目 | 结果 |
|---|---|
| 接触中心 | X150、Y125、Z0mm |
| 机身参考高度 / 俯仰 | 约61.93mm / 60° |
| 肩pitch / roll / 新增旋转 / 肘 | 约-73.63° / 8.31° / -149.22° / 74.08° |
| 护腕安装旋转 | 180°候选 |
| 接触垫角点到平面误差 | 数值上小于0.01mm |
| 手掌最低位置 | 地面上方约0.5mm |

这里的小数表示数值复现精度，不能解释为制造公差。新增肩旋转接近当前假定角限位，实际驱动安装和ROM尚未确认。

关键限制是机身很低：尚未证明膝、脚能放在地面上且与躯干不干涉，也没有足够质量/接触力证明平衡。此姿态只能进入下一轮全身起身路径验证，不能称为机器人已经能起身。额外两个XM430级电机本体参考增重164g，还需计支架和配线。

我建议保留28 DOF作为优先验证候选，分配为腿12、双肩6、肘2、腕4、夹爪2、颈2。提案见 `03_system/dof_proposal_v17.json`。现有零位、控制通道和策略不会自动升级。
