# 桌面递水任务 v0.1

## 用户确认的场景

机器人站在桌面，从旁边拿取一瓶 550 mL 矿泉水，递给坐着的用户。

## 工程暂定条件

- 满瓶、有瓶盖、初始直立；实际瓶型、瓶径、高度、包装质量待获取。
- 优先比较双手抱持方案。夹持高度和抓取方式由几何、摩擦和驱动校核确定，不假定夹持瓶盖或瓶颈。
- 取瓶时允许下蹲和身体姿态调整；递交阶段优先原地完成，用户主动伸手接收。
- 不要求机器人越过桌沿，不默认需要携瓶行走。
- 尚未定义抓取成功率、递交时间、允许瓶子倾角和重复次数。

## 待计算的动作序列

1. 确认瓶子位置及可操作区域，判断是否在可达范围内。
2. 调整双臂和身体姿态，双手接近并建立夹持。
3. 小幅抬瓶，检查夹持与负载是否稳定。
4. 将瓶子移到靠近躯干的持握位置，检查全身平衡。
5. 在支撑与关节负载允许的范围内前伸递交。
6. 确认用户已经接住后释放，恢复空载姿态；不以视觉检测到手就自动认定承重已转移。

## 验证输出

- 各关键姿态的 IK、关节余量、手/瓶/躯干碰撞检查。
- 逐阶段机器人与瓶子联合 COM、支撑条件及动态余量。
- 双臂负载分配、夹持防滑和连续/峰值扭矩。
- 相机视野、近距盲区、瓶身成像与定位可用性；透明瓶的识别和深度质量需用目标器件实测，不假定深度始终有效。
- 受限递交区域、拿取/释放失败处理及重复测试记录。

当前只有任务定义，尚无模型、IK 或实测结果。
