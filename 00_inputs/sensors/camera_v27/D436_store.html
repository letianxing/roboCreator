    The RealSense™ Depth Camera D436 features a broad field of view global shutter D430 optical module, with a matching global-shutter RGB sensor synchronized with the depth sensors.
    Details

    RealSense™ Depth Camera D436 combines the depth sensing capabilities of the D435 with a global shutter 90o FOV RGB sensor.

    The RealSense D436 includes:

    • D430 Optical module
    • Vision Processor D4 Board V3
    • An inertial measurement unit.
    • The RealSense SDK 2.0 which provides a depth and IMU data stream.
    • Desktop tripod.
    • USB-C* cable.

    For more information regarding RealSense™ Depth Cameras and RealSense™ technology, go to realsenseai.com

    The latest release of the RealSense™ SDK 2.0 is available on our GitHub page at https://github.com/IntelRealSense/librealsense/.

    WARNING This product can expose you to Antimony oxide (Antimony trioxide), which is known to the State of California to cause cancer. For more information go to www.P65Warnings.ca.gov.
