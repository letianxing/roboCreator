# 可落地性检查与材料初选

状态：工程验证方案，不代表已通过验证。

## 材料初选

- PLA：外形/装配试样、低受力装饰件优先候选；最终外壳仍检查碰撞与接触风险。
- PETG：承力打印框架和需要韧性的外壳优先候选；最终依据牌号、打印方向、刚度、层间强度、蠕变与温升验证。
- 轴、轴承、关键紧固件采用合适的标准件；关键支撑节点按需比较金属轴套/支架，不能默认所有承力件都用塑料。
- 足底及抱瓶接触面评估购入的橡胶/硅胶等防滑件，不要求打印店增加打印材料种类。
- 不冻结壁厚、填充率、公差和允许温度，直到完成几何/受力分析并取得工艺条件。材料 TDS 值不是成品许用应力。

来源：Bambu PETG HF 官方介绍指出其相较 PLA 的韧性和耐久性优势；这仅支持初选方向，不代表未知牌号的等效性能。

## 高风险环节与证据

| 环节 | 必需检查 | 通过证据 |
|---|---|---|
| 550 mL 满瓶拿取与递交 | 几何、夹持摩擦、腕/肩肘载荷、支撑及卸载 | 轨迹计算、夹持台架实测、整机重复递交 |
| 四类地面自主起身 | 仰躺/俯卧/侧倒恢复、手臂支撑、足底打滑 | 全轨迹 ROM/碰撞/动力学检查，各地面实测 |
| 被击倒 | 定义击打方式/能量和接触部位、结构/传动冲击 | 受控分级试验及损伤记录，不能靠起身测试替代 |
| 稳定运动 | 姿态、接触、执行器反馈、时延、状态估计 | 基础控制、轨迹与模型一致性、实测稳定性 |
| 电气 | 相/母线电流、压降、回生、热、保护、时序 | 供电预算与带载测试、故障处理验证 |
| 塑料与接头 | 层方向、座孔/嵌件、刚度、蠕变、温升 | 同工艺试样、接头加载与保持试验 |
| 成本 | 驱动、感知、制造、配套及返工 | 可追溯报价 BOM ≤5,000 元；算力单列待确认 |

## 推进顺序

1. 收敛行为/自主程度及关键工况，建立参数化几何与 21/24 DOF 对比。
2. 根据全身质量预算、力臂和轨迹计算驱动需求，核对厂商性能与价格。
3. 优先制作单关节支撑、打印接头、双手抱瓶等高风险样件，避免先外包整机再发现基本负载不足。
4. 通过关键验证后制作整机，开展标定、辨识、基础控制与仿真训练。
5. 分级验证起身、硬地面与接触对打，并在更换角色外壳后重验。

若任一关键项超出约束，记录明确的缺口和调整方案，不通过乐观参数强行宣布可行。用户已授权调整自由度，但未授权突破总预算或降低核心能力。
