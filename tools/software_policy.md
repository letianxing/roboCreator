# 软件与 MCP 的引入规则

用户于2026-09-06明确要求：如果步骤需要开源软件＋MCP，先询问用户。

后续引入新开源软件、安装依赖/工具、接入新MCP或更改MCP配置前，先给出：用途、为什么现有工具不够、候选方案与开源来源、安装位置、权限/网络/资源影响、是否需要重启及费用。得到同意后再实施。此要求优先于最初“需要工具可直接安装”的授权。

可以先做现有环境的只读检查、资料调研、配置草稿和其他不依赖新增工具的工作。不要以“开源/免费”为理由跳过询问；不要把许可、账号、采购与MCP配置混成一次默认授权。

v0.18使用已有FreeCAD后台与Python进行CAD/计算，建立本地PLM/MES文件与验证脚本；没有安装新PLM/MES/CAE平台，也未增加MCP服务器。正式平台选型尚待后续步骤提出并经用户确认。
