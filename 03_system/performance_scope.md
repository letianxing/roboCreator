# 表演动作与角色平台：需求扩展

状态：需求分析，尚未进行动力学、结构或训练验证。

## 新增目标

悟空需要猴戏、武术和打斗展示能力；后续六耳猕猴、杨戬尽量复用基础平台。当前首台样机约束仍为 30–40 cm、21 个驱动自由度、人民币 5,000 元上限。

## 设计影响及后续工作

- 将表演动作展开为具体姿态和轨迹，再检查 ROM、速度、加速度、支撑、碰撞和扭矩；不将笼统的“武术”作为可计算工况。
- 无接触编排、轻接触和实际击打/推倒需要分别建模。接触等级未确认前，不虚构冲击力或承诺承受打击。
- 当前 12 腿 + 6 臂 + 2 夹爪 + 1 头的分配仅为候选。新增动作需要重新检查无腰、无腕方案的表现力及工作空间，不能视为已定型。
- URDF 提供基础结构描述；可训练环境还需要执行器模型、接触、控制、观测/动作定义和任务配置。训练成功仍需真机验证。
- 通用平台拟统一安装接口、关节命名、电控及基础结构；角色外壳、衣服和可能的道具使用独立版本。每种配置重新计算质量、COM、惯量和碰撞包络，检查是否需要策略调整或再训练。
- 上海外包打印成本必须包含试打、公差样件、后处理和返工，现有制造费用额度仅为待报价的目标。

## 优先待确认

已确认需要被击倒后自主起身，也需要主动躺下躲避后自主起身。实际冲击程度仍未量化。优先确认地面材质和场地，随后核实材料名称、关键动作、典型抓取物体和资源条件。

## 倒地与自主起身工况清单

以下是工程待验证项，不是已实现能力或用户逐项确认的验收条件：

| 工况 | 主要检查 |
|---|---|
| 主动下降到躺姿 | 下降轨迹、支撑转换、头部及外壳接触、关节余量 |
| 接触失衡后倒地 | 接触位置和速度、跌落能量、地面顺应性、结构及传动冲击 |
| 仰躺起身 | 躯干/腿/手臂协调、手臂支撑、峰值及持续扭矩 |
| 俯卧起身 | 肩肘支撑力、夹爪保护、膝足接触与重心转移 |
| 侧倒恢复 | 翻转到可起身姿态、碰撞与关节范围 |
| 穿戴盔甲后的重复恢复 | 外壳卡滞、衣物卷入、温升、松动及累积损伤 |

被击倒与主动躺下必须分开验证；受控下降测试不能替代被动跌落验证。脚本化表演与自主感知躲避也需分开定义，当前尚未确认自主感知要求。

先由地面、整机质量、重心高度和具体接触方式建立工况，再计算冲击和驱动需求。现阶段不赋予虚构的耐冲击数值，也不承诺在 5,000 元内通过全部工况。
